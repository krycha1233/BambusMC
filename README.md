# 🎋 BambusMC

Oficjalna strona internetowa serwera Minecraft **BambusMC** działającego na platformie [Aternos](https://aternos.org).

**Adres serwera:** `bambusmc.aternos.me`

---

## ✨ Co znajdziesz na stronie?

- **Kopiowanie IP** jednym kliknięciem
- **Sklep serwerowy** – doładowanie `/portfel` za pomocą kodów **Paysafecard (PSC)**
- Nowoczesny, responsywny design w stylu bambusowym 🎋
- Integracja z Discordem

---

## 🚀 Jak uruchomić stronę na GitHub Pages?

1. Utwórz nowe repozytorium na GitHubie (np. `bambusmc` lub `nazwa-uzytkownika.github.io`)
2. Wrzuć do niego pliki:
   - `index.html`
   - `README.md`
3. Wejdź w **Settings → Pages**
4. W sekcji **Source** wybierz branch `main` (lub `master`) i folder `/ (root)`
5. Zapisz – po chwili strona będzie dostępna pod adresem:
   ```
   https://twoja-nazwa.github.io/nazwa-repo/
   ```
   lub
   ```
   https://twoja-nazwa.github.io/
   ```
   (jeśli repozytorium nazywa się `twoja-nazwa.github.io`)

## 💳 Sklep – Paysafecard

Formularz wysyła dane (nick + kod PSC + kwota) na maila administratora przez [FormSubmit](https://formsubmit.co).

Po wysłaniu gracz otrzymuje potwierdzenie, a administrator dostaje powiadomienie.

---

## 🛠️ Technologie

- Czysty HTML + CSS + JavaScript (bez frameworków)
- FormSubmit.co – obsługa formularza kontaktowego
- Responsywny design (działa na telefonach i komputerach)
